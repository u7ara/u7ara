# Trees of the day

One featured photo shown on the home page, under "Recent writing".

- Drop **any single image** here (`.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`).
- The section hides itself automatically while this folder has no images.
- If you keep more than one, the file whose name sorts last wins — so
  date-prefixed names like `2026-10-21.jpg` rotate naturally.
- Delete or replace the file to change the photo. No code edits needed.
